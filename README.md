# ♠♥ ポーカー練習場 — オフライン Texas Hold'em

ブラウザだけで動く、**完全オフライン**のテキサスホールデム（ノーリミット）練習アプリです。
サーバー不要・データ送信なし。`index.html` を開くだけで遊べます。

## 主な機能

### 🎮 CPU対戦モード
- 1〜5人のCPUと対戦（ヘッズアップ〜6max）。
- CPUは以下を総合して意思決定します:
  - **勝率推定**: モンテカルロ法で手札のエクイティ(勝率)を算出
  - **ポットオッズ**: コールに必要な勝率と比較
  - **ポジション**: 後ろのポジションほど強気に
  - **プレイスタイル(性格)**: ロック / TAG / LAG / コーリングステーション / マニアック
- ブラインド、サイドポット、オールイン、ショーダウンに対応。
- あなたの番では**推定勝率と必要勝率(ポットオッズ)**をヒント表示。
- フォールド / チェック・コール / レイズ（スライダー＋½ポット・ポット・オールインのプリセット）。

### 📘 戦略学習モード（最新＝GTOベース）
- **レッスン**: GTOの基礎、ポジション、プリフロップレンジ、ポットオッズとエクイティ、
  Cベットとボードの質感、ベットサイズ設計、メンタル&バンクロール。
- **🎯 プリフロップ・レンジトレーナー**: 配られた手札とポジションから、
  オープン(レイズ)/フォールドを即断する反復練習。
- **🧮 ポットオッズ・クイズ**: 4-2の法則とポットオッズで、ドローのコール/フォールドを判断する練習。

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK。インストール不要）。
2. 上部タブで「CPU対戦」「戦略学習」を切り替え。
3. CPU対戦は人数・スタック・ブラインド・演出スピードを設定して「ゲーム開始」。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `css/style.css` | 画面とスタイル |
| `js/cards.js` | カード・デッキ |
| `js/evaluator.js` | 7枚からの役判定 |
| `js/ai.js` | CPUの勝率推定と意思決定 |
| `js/game.js` | ゲーム進行エンジン（ベッティング・サイドポット・ショーダウン） |
| `js/strategy.js` | 戦略レッスン本文とトレーナー用データ |
| `js/ui.js` | テーブル描画・操作 |
| `js/main.js` | 画面の配線 |

## 補足
- 勝率は乱数シミュレーションのため、毎回わずかに変動します（概算）。
- レンジ表は学習用の簡易版です。実戦では相手に応じた調整(エクスプロイト)も重要です。
